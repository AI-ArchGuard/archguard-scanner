# ArchGuard Scanner v0.2.0

首个可独立运行的 ArchGuard Scanner 版本，提供 Java 21/Maven 静态事实提取、语言无关的 `0.1.0` 结果契约、八条确定性结构规则，以及离线 CLI。

## 包含内容

- 稳定的 Artifact、Component、Dependency、Metric、Finding 与 Evidence 模型。
- 非法包依赖、分层、循环、Spring Controller→Repository、内部模块、禁止组件、圈复杂度和必要注解规则。
- 严格的 `0.1.0` YAML 配置、确定性 JSON、稳定 ID、原子报告写入和明确退出码。
- 文件、字节、图、Finding、输出与总扫描时间上限。
- 三个公开合成项目、三个失败夹具、黄金 SHA-256、三次字节级复现与 CI 性能上限。

## 资产

- `archguard-scanner.jar`：需要 Java 21 的可执行 shaded JAR。
- `archguard-scanner.jar.sha256`：对应 JAR 的 SHA-256 校验和。

## 使用

```bash
java -jar archguard-scanner.jar scan ./repository \
  --rules ./archguard-rules.yaml \
  --output ./report.json
```

退出码：`0` 成功；`2` 存在达到 `failOn` 门槛的 Finding；`64` 参数或配置无效；`70` 扫描、资源、Diagnostic 或报告失败。

## 已知限制

本版本只静态分析 Maven `src/main/java` 与直接声明的非测试依赖；不执行 Maven、不下载依赖、不解析传递依赖、不提供完整 Java 类型求解或 Spring 运行时语义。Diagnostic 由 CLI 输出，不进入 `0.1.0` 报告 JSON。
